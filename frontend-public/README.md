# Inactive React archive

Production uses Go templates and vanilla JavaScript in `web/`. This directory is kept for reference only: release CI does not build it, and the normal `embed` build tag does not include it (`-tags 'archive embed'` opts in explicitly).

- Its design document is [docs/archive/design_ts.md](../docs/archive/design_ts.md).
- For the current code, see [architecture](../docs/develop/architecture.md) and the [docs index](../docs/README.md).
