Message template variables

Use these in a custom webhook payload. They are filled in when the alert fires.

{{template "modal_close"}}

Payloads are Go templates. These variables are available:

Variable Type Description
{{.Alert.Nickname}}stringName of the firing alert rule
{{.Agent.Nickname}}stringTarget server node nickname
{{.Agent.AgentID}}stringTarget server unique agent ID
{{.Incident.Value}}float64Measured metric value that caused the breach
{{.Incident.Status}}stringIncident status ("firing" or "resolved")
{{.Incident.TriggeredAt}}time.TimeUTC timestamp of breach start
{{end}}
