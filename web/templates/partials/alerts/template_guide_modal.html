Message template variables

Use these in a custom webhook payload. They are filled in when the alert fires.

{{template "modal_close"}}

Use these placeholders inside JSON strings:

Variable Type Description
{{NICKNAME}}stringTarget node nickname
{{AGENT_ID}}stringTarget node ID
{{TRIGGER_LABEL}}stringAlert metric name
{{VALUE}}stringFormatted metric value
{{STATUS}}stringFIRING or RESOLVED
{{TIME_TRIGGER}}stringIncident start time
{{TIME_RESOLVED}}stringIncident recovery time
{{MONITOR_ID}}stringNetwork monitor ID
{{MONITOR_TARGET}}stringNetwork monitor target
{{MONITOR_PROTOCOL}}stringICMP, TCP, HTTP or DNS protocol
{{DNS_SERVER}}stringCustom DNS server, when configured
{{end}}
